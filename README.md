# Mazot Takip

Bu klasör, tam çalışan (veritabanına bağlı) mazot takip uygulamasının kaynak kodudur.
Kurulum adımları için Claude'un sohbette verdiği adım adım talimatı takip edin.

Yerelde denemek isterseniz:
1. `npm install`
2. `.env.example` dosyasını `.env.local` olarak kopyalayıp Supabase bilgilerinizi girin
3. `npm run dev`
